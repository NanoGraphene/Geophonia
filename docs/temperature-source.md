# Land-capable source: GEOS-FP near-surface temperature

NASA page: https://svs.gsfc.nasa.gov/5147/ . An Earth Information Center resource related to the supplied GEOS Aerosols page, added for land sound debugging. Model GEOS-FP; credit NASA’s Global Modeling and Assimilation Office, visualizer Joseph V. Ardizzone (NASA/GSFC). Preserve embedded NASA/GMAO credit and follow NASA media guidelines; no endorsement is implied.

Exact source, SHA-256, legend and local files: `public/data/temperature-manifest.json`. Source snapshot is 2048×1024; full image has visually aligned equirectangular global extent [-180,-90,180,90]. Greenland, South America, Africa, Madagascar and Australia correspond with the established geographic geometry. No CRS/geotransform is embedded; this is empirical geographic alignment and does not verify exact shoreline positions. Nearest-neighbor resampling produces the same 1536² Web Mercator extent as the ocean display.

Visible date label: 29 Oct 2026 05:00:00 EDT, equivalent to 2026-10-29T09:00:00Z. Scientific/model averaging interval is unverified. The rolling source directory may later change its contents; committed PNGs freeze this snapshot and preprocessing checks the original hash. The page says both 2 m and 3 m sampling height; do not invent a resolved height.

The independent source colorbar spans -40 to +40 °C, with non-monotonic hue, white and gray colors. A dedicated literal RGB nearest-color matcher samples row 90, columns 74–461 of that colorbar. Maximum Euclidean RGB distance is 120 on 8-bit channels. Source top-left logo region [0,0,350,85] and bottom-left date region [0,930,520,1024] are excluded. Pixels outside those rectangles are not inferred missing merely because they are gray. Palette ties resolve to the first occurrence. Terrain shading/compositing and repeated colors can shift or ambiguously invert the apparent palette position; do not report scientific temperature from this renderer.

Pitch is the neighborhood mean normalized visual palette position; loudness is matched-color pixel fraction, labelled “Matched color coverage”, not physical concentration. Neighborhood options and normalization stay fixed. Masked/unmatched pixels produce null data and never a fabricated zero. The land/water filter remains driven only by the independent geographic mask. Both land (Sahara and Australian interior) and ocean regression patches are extracted from the real frame and pass sampling/classification tests. No synthetic replacement NASA data is used.

Current implementation loads three frozen dated frames per dataset as a small manual time series. Loading freezes no old value under a new date: clear sample and fade sound, preload and decode all assets, then commit source metadata/image/sample together only for the current request. Failure leaves sample unavailable and allows retry or dataset switching.
